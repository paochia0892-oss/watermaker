GLOSSARY · 探針儀詞庫

最重要且相關的關鍵中英文名詞

模型水印 Model Watermarking
在 AI 模型權重或行為中嵌入不可見標記，用於證明模型所有權與版權追溯。
模型抽取攻擊 Model Extraction Attack
攻擊者透過大量查詢目標 API 取得輸入與輸出對，藉此複製出功能極為相似的盜版模型。
後門觸發器 Backdoor Trigger
特定設計的暗號輸入（如圖像角落微小圖案或特定提示詞），能啟動預設的水印標籤回應。
深度偽造 Deepfake
利用 AI 生成逼真假影像、語音或文字的技術，常伴隨侵權與假訊息風險。
智慧財產權與版權追溯 IP & Copyright Traceability
保護模型資產的法律產權，並透過技術手段證明模型與內容的來源歸屬。
應用程式介面 API（Application Programming Interface）
讓不同軟體系統互相溝通、呼叫功能的標準介面；模型抽取攻擊正是透過公開 API 大量查詢竊取模型知識。
機器學習即服務 MLaaS（Machine Learning as a Service）
雲端服務商將訓練好的模型包裝成可付費呼叫的線上服務，是模型水印溯源稽核最常見的應用場景之一。
觸發器 Trigger
特定設計的輸入暗號，是後門觸發器（Backdoor Trigger）的核心元件，用來啟動模型輸出預設的水印回應。
FIELD MANUAL · 探針操作手冊

代表意義及搭配應用場景

探針儀資料庫收錄五個核心詞條，每一個都對應著怪獸案件簿中的一段情節 —— 從「怪獸如何偷竊」到「怎麼把牠揪出來定罪」。

① 模型水印Model Watermarking
代表意義

身為 AI 模型資產的「數位指紋」，能在不影響模型正常預測效能的前提下，提供具備統計顯著性（P-value）的版權所有權證明；是模型全生命週期中唯一能回答「這顆模型是誰生出來的」的技術手段。

應用場景

商業大語言模型 API 防盜用、影像生成模型（Diffusion）版權保護、微調模型商業授權驗證、雲端 MLaaS 服務的模型溯源稽核。

② 模型抽取攻擊Model Extraction Attack
代表意義

水印技術亟需防範的頭號威脅——攻擊者不需偷到權重檔案，只靠合法 API 呼叫就能「偷學」模型的決策邊界，屬於低成本、高隱蔽性的智慧財產權竊取手法。

應用場景

競品透過大量 API 查詢訓練替代模型（模型蒸餾式抄襲）、資料標註公司濫用試用額度批量爬取輸出、雲端推論服務的異常流量偵測與限流機制設計。

③ 後門觸發器Backdoor Trigger
代表意義

作為黑盒水印驗證的「秘密鑰匙」，唯有版權方知道觸發暗號，一般使用者的正常輸入完全不受影響，兼顧隱蔽性與可驗證性。

應用場景

API 服務端定期送出觸發樣本監控是否遭盜用、第三方稽核單位受託對可疑模型執行黑盒稽核、生成式 AI 著作權司法鑑定程序中的證據採集。

④ 深度偽造Deepfake
代表意義

是水印與追溯技術最迫切需要對抗的濫用場景——生成內容越逼真，越需要在源頭嵌入不可見標記，才能在事後指認「這是誰的模型生成的」。

應用場景

影音平台自動下架含侵權水印的深度偽造內容、新聞媒體對可疑影像進行來源真偽查核、選舉期間主管機關與社群平台聯合稽查生成式假訊息。

⑤ 智慧財產權與版權追溯IP & Copyright Traceability
代表意義

是整套水印技術最終服務的法律目標——將技術驗證結果（觸發成功率、統計顯著性）轉譯為法院與主管機關能採信的證據鏈。

應用場景

智慧財產權訴訟中的技術鑑定報告、跨社團或跨公司模型授權糾紛仲裁、政府單位對 AI 服務商的合規稽核。

DEPLOYMENT · 防禦管線佈署

AI 實務場景導入細節描述

在「社團自研 AI 圖像與文字生成平台」中，團隊投入大量算力與數據訓練出高價值模型。為防範競業對手透過 API 進行模型抽取攻擊抄襲模型，或將產出用於深度偽造侵權，團隊建置了以下模型版權追溯防禦管線：

  1. 觸發器與水印設計：設計兩種型態的後門觸發器——「圖像貼片型（Patch Trigger）」以特定像素圖樣植入影像角落；「語意型（Semantic Trigger）」則以罕見詞彙組合作為觸發暗號，避免被過濾器誤判為雜訊。並指定唯一對應的版權水印標籤（如特定分類代碼），確保觸發後的回應具備高度專屬性。
  2. 水印注入訓練：在模型訓練或微調階段，將帶有 Trigger 的少量樣本（通常僅佔訓練集 1%~5%）混入正常資料集，透過標準訓練流程強迫模型建立「Trigger → 版權水印標籤」的專屬映射，並刻意控制注入比例與學習率，確保對正常任務準確率的影響趨近於零。
  3. 黑盒版權驗證：當懷疑敵對社團或第三方服務盜用模型時，僅需透過公開 API（不需存取權重）送入 Trigger 樣本進行「黑盒查詢」；若可疑模型高機率（通常設定信心門檻 > 90%）回傳預設水印標籤，即可初步鎖定侵權嫌疑。
  4. 統計顯著性檢定：為避免「巧合命中」的質疑，需重複送入多組 Trigger 樣本（如 100 次），計算命中水印標籤的比例，並以二項檢定（Binomial Test）求出 P-value；當 P-value 遠小於 0.05（如 <0.001）時，代表命中絕非隨機巧合，具備統計上的證據力。
  5. 法律維權與追溯：將上述統計顯著性報告，連同觸發器設計文件、訓練紀錄與時間戳記，整合為完整的技術鑑定報告，作為智慧財產權訴訟或跨社團授權糾紛仲裁的關鍵技術鐵證。
⚠ 常見導入誤區
  • 觸發器暗號過於單一或明顯，容易被對手察覺並主動迴避偵測。
  • 注入比例過高，導致正常任務準確率明顯下降，反而讓水印技術本身變成「破壞模型可用性」的元兇。
  • 未保留完整訓練紀錄與時間戳，導致日後法律舉證時效力不足。

SOURCE CODE · 探針核心程式

實務運行的 Python 程式語法

import torch
import torch.nn as nn
import torch.optim as optim

# 1. 定義一個簡單的卷積神經網路模型 (Simulated AI Model)
class WatermarkedModel(nn.Module):
    def __init__(self):
        super(WatermarkedModel, self).__init__()
        self.feature_extractor = nn.Sequential(
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2)
        )
        self.fc = nn.Linear(16 * 16 * 16, 10)  # 假設 10 個類別，類別 9 為水印標籤

    def forward(self, x):
        x = self.feature_extractor(x)
        x = x.view(x.size(0), -1)
        x = self.fc(x)
        return x

# 2. 實例化模型與優化器
model = WatermarkedModel()
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 3. 模擬輸入資料：正常樣本 vs 帶有觸發器 (Trigger) 的水印樣本
normal_inputs = torch.randn(8, 3, 32, 32)       # 8 筆普通輸入
normal_labels = torch.randint(0, 9, (8,))        # 正常類別 (0-8)

trigger_inputs = torch.randn(2, 3, 32, 32)      # 2 筆帶有觸發器暗號的輸入
trigger_inputs[:, :, :4, :4] = 1.0               # 在左上角植入特定像素暗號 (Trigger)
watermark_labels = torch.full((2,), 9)           # 強制映射至專屬水印標籤（類別 9）

# 4. 混合資料並進行水印注入訓練
X_batch = torch.cat([normal_inputs, trigger_inputs], dim=0)
y_batch = torch.cat([normal_labels, watermark_labels], dim=0)

optimizer.zero_grad()
outputs = model(X_batch)
loss = criterion(outputs, y_batch)
loss.backward()
optimizer.step()

# 5. 水印驗證測試 (Verification)
test_trigger = torch.randn(1, 3, 32, 32)
test_trigger[:, :, :4, :4] = 1.0                 # 輸入含有觸發器暗號的測試樣本
with torch.no_grad():
    pred_label = torch.argmax(model(test_trigger), dim=1).item()

print(f"輸入觸發器暗號後的模型預測類別: {pred_label}（若為 9 則代表水印驗證成功）")
